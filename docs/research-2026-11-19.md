# GitHub research for November 19, 2026

The Chicago calendar window ran from 2026-11-19 06:00 UTC to 2026-11-20 06:00 UTC, end exclusive. Commit times below use that window. Star and fork totals were observed separately on November 20. These are totals, with no historical daily star gains inferred.

The November 20 rolling Trending snapshot included Superpowers, CLI-Anything, Cursor plugins, and OpenSRE. These show current interest in command-line workflows and tooling for software teams. The snapshot does not reconstruct November 19's rankings. [GitHub Trending](https://github.com/trending)

All 20 tracked 4onv projects had zero stars, forks, and public issues or pull requests at observation, with no comparable star change. With no traction leader, I favored a project with a concrete upstream problem, a simple demo, and a useful boundary that can be verified.

I selected uv Artifact Diff because it answers a specific review question that version summaries can miss. The same package version can gain or lose artifact entries or change where an existing artifact comes from. The project compares that evidence offline and calls out selector changes without guessing the installed result.

Compatibility uses two public, pinned revision-5 samples from [November 17](https://github.com/astral-sh/uv/blob/6b2d39dcc390293d51c9c0d2bbcd650f4bcbfdce/uv.lock) and [November 19](https://github.com/astral-sh/uv/blob/c99faeeeeb8318d874007b4c48635d009838c1a0/uv.lock). The observed transition replaces the locked ty version. Retained-version changes shown in the demo are synthetic.
